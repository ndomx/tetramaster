# M1.08 - Isolate CPU Move Selection

## Objective

Make CPU policy a replaceable chooser that selects from engine-provided legal
actions but cannot apply actions or mutate the session.

## Prerequisites

- M1.07 is complete.
- The human has approved the initial policy: preserve current random card and
  position selection unless explicitly changed.

## Scope

- Add an `ai` module with a read-only input containing the CPU-visible state and
  legal CPU actions.
- Preserve the current random policy using the engine's seeded randomness.
- Return a `GameAction`; apply it later through the same internal validation path
  used for human actions.
- Test that the AI chooses only legal actions and is deterministic for a seed.

## Non-goals

- No strategic AI, difficulty levels, direct session mutation, frontend exposure
  of CPU cards, dependency changes, or Cargo edits.

## Acceptance Criteria

- AI code cannot mutate `Board`, `Player`, or `GameSession`.
- Session orchestration remains responsible for applying the selected action.
- CPU choices are legal and reproducible.
- The TUI and existing game behavior remain functional.

## Verification

```sh
cargo fmt --check
cargo test
cargo clippy --all-targets -- -D warnings
cargo run
```
